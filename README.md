# Emote Shelf

Локальный плагин Dalamud для закладок на эмоции из модов Penumbra. `/eshelf` открывает настройки, `/eshelf scan` обновляет список, `/eshelf show` и `/eshelf hide` управляют перемещаемой панелью.

Плагин ищет в установленных модах замены `.pap` по путям `/emote/`. Команду вроде `/flamedance` он берёт из описания мода, если там явно написано `replaces /flamedance`; для других модов команду нужно вписать вручную. Нажмите `+`, чтобы закрепить пару «мод–команда» на панели. Одному моду можно добавить несколько закладок.

Для разных вариантов одной эмоции настройте мод в Penumbra, создайте закладку и нажмите у неё «Запомнить опции». Затем выберите другой вариант в Penumbra, создайте вторую закладку и снова запомните опции. Названия кнопок можно изменить. Закладка без сохранённых опций использует текущие настройки мода.

При нажатии плагин находит коллекцию персонажа, временно включает выбранный мод с приоритетом выше обнаруженных конкурентов для тех же `.pap` и запускает игровую команду эмоции. Остальные моды не выключаются. Временная настройка остаётся до следующего выбора, ручного сброса или выгрузки плагина, чтобы длинные танцы не прерывались. Если другой мод перекрывает ту же анимацию через путь, который сканер не распознал, результат нужно проверить в игре.

Требуется Penumbra. Эта версия не проверена в запущенной игре; сначала протестируйте на одной закладке. Сборка проекта использует установленный Dalamud SDK и `Penumbra.Api.dll`; `latest.zip` создаётся SDK в `bin/Release/EmoteShelf/`.
